# Booking System – individual coding exam

This is a starter project for the individual practical coding exam. The
application targets .NET 10 and contains a console application and xUnit tests.

## Requirements

- .NET 10 SDK

## Run the application

```bash
dotnet run --project src/BookingSystem
```

## Run the tests

```bash
dotnet test
```

Read the separate assignment instructions before starting. The existing code
is incomplete and contains intentional defects.

# Booking System

Detta är en konsolbaserat bokningssystem som är utvecklad i C# och .NET

## Starta app

- Börja med att antingen klona eller ladda ner från GitHub
- Öppna rätt fil i Visual Studio "BookingSystemExam.sln"
- Se till att "BookingSystem" är markerad som startup-projekt
- Starta konsoleapplikationen, antingen med att trycka på "play" knappen eller F5

## Köra xUnit Tester

- Gå igenom steg för att starta app fram till steg 4.
- Gå till BookingSystem.Tests
- Tryck på View => Test Explorer
- Antingen tryck på "play" knappen som är grön
- Eller tryck på fliken Test => Run All Tests
